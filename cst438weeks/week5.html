Summarize in a few sentences what you have learned this week.

Having a strong overall "mapped out" understanding of Controllers, Repositories, Entities, DTOs, and Services is a lot harder than I imagined. Spent this week creating prompts of custom questions for each of the following categories I mentioned in the last sentence so that I can test myself. Most of the questions deals with me having to write code out so that I get a better syntax recognization and code reading ability in the React and Spring ecosystem.

Here's an example of such question I wrote for myself:

Question 6 Method Declaration

Your API already has this controller:

@RestController
public class StudentController {

}

A client should be able to request:

GET /students/15

When this request arrives:

It should call a method named getStudent
The method should return a Student
The student's ID comes from the URL
Write the method declaration.

The purpose of such question is so that I can improve my "freestyle" coding ability. A question is: why put myself through this rather "useless" skill when we have AI that can instantly perform such mundane task. It is because being able to know and create from scratch implies by that point that I have a strong understanding of how everything is put together. For example, by practicing manually writing out Controller files, I know have a better intuitive grasp of how and when entities or repositories are called in endpoints within a Controller file. This can become handy in spotting errors, gaining intuitive ability in where to make changes, and read and proofread AI's output more efficiently.
