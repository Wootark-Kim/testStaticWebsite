Describe some of the differences between using an Agile process and using a Plan and Document (or Waterfall) process.

Not going to lie, but Agile development definitely feels like a more structured version of "wing it" kind of vibe I used to feel when doing group projects. One with a lot less chaos. I say this because it is such an iterative-focused process where polishing and deadline starts to become more visually realized as we go further along the project. I would say it is the flexibility of allowing changes where a great deal of mental energy cost is saved that makes Agile method so valuable.

I do much prefer Agile development as I find Plan and Document process far too strict. In a smaller scoped project or for early prototypes, I think the Plan and Document process is perfectly fine; however, for larger projects, changes in development can feel so incredibly difficult and costly since a small change starts an entire cascade of changes upstream in anticipated future development (since Plan and Document entails that we write out the entire details of the implementation plan out first).
