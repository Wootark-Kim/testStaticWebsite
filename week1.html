What is an Algorithm?

I've learned that algorithm is a sequence of unambiguous instructions for solving a problem for obtaining a required output for any legitimate input in a finite amount of time (thus why eventually Big O notation will become such a big deal later on).

A beginning problem we focused on was finding the greatest common denominator (gcd) when given 2 integers. One of the algorithm we've learned to solve this is called "Euclid's Algorithm." It is defined as the repeated application of the equality:

gcd(m, n) = gcd(n, m mod n)
until the second number becomes 0, at which point the first number becomes the answer. Using JAVA, I can demonstrate Euclid's algorithm using either an iterative version or a recursive version:

Iterative Version:

public static int gcd(int a, int b){
while (b!=0){
int remainder = a%b;
a=b;
b=remainder;
}
return a;
}
Recursive Version:

public static int gcd(int a, int b){
if (b==0) {
return a;
}
return gcd(b, a%b);
}
A cool thing to add on is that apparently every iterative solution can be implemented as a recursive solution and vice versa. This is described as iteration and recursion being "expressively equivalent."

With that being said, a problem can be solved using multiple algorithms. Another one which can solve the gcd problem is using the Consecutive Integer Checking Algorithm approach. It is defined as:

  1. Assign the value of min {m, n} to t
  2. Divide m by t. If the remainder is 0, go to step 3; otherwise go to step 4
  3. Divide n by t. If the remainder is 0, return t and stop; otherwise go to step 4
  4. Decrease t by 1 and go to step 2

Recursion vs Iteration

Iterative algorithm uses loops and data structures like stacks and queues to solve a problem.

Recursive algorithm is an algorithm which calls itself again and again until a base condition is achieved.

Types of Problems

So if algorithms are used to solve problems, then what types of problems will I come across? Some of the most common and important problem types I need to become familiar with are:

  • Sorting
  • Searching
  • String processing
  • Graph problems
  • Combinatorial problems
  • Geometric problems
  • Numerical problems
Take for example the palindrome. That one is an example of a String Processing problem, whereas the GCD problem (where I would use Euclid's algorithm to solve it) is an example of a Numerical Problem.
